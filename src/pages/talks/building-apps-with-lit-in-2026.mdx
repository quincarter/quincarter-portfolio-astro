# Building Apps with Lit Element in 2026

I gave this talk twice this year — first at Capital One's internal conference, Async Live, in April, then again at the RVA.js Meetup in August. It covers what it actually takes to build a real, production-shaped application with Lit: app shell structure, routing, dependency injection with `@lit/context`, async state with `@lit/task`, a `ViewMixin` pattern for standardizing pages, and signals for lightweight state management.
